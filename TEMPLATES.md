# Как изменить шаблон поста

Вид постов в канале можно менять прямо в Telegram, через бота. Программист для
этого не нужен.

Шаблонов четыре:

| Шаблон                | Где используется                                           |
|-----------------------|------------------------------------------------------------|
| 📱 Смартфони          | посты смартфонов                                           |
| 📟 Планшети           | посты планшетов                                            |
| 💻 Ноутбуки           | посты ноутбуков                                            |
| 📝 Підвал (контакти)  | блок в конце **каждого** поста: услуги, сайт, адрес, телефон |

---

## Пошагово

1. Отправьте боту `/template`.
2. Выберите категорию. Бот пришлёт:
   - список доступных **полей** и **пометок** (что это — ниже);
   - **текущий шаблон** отдельным сообщением.
3. Скопируйте сообщение с шаблоном: нажмите на него и держите → «Копировать».
4. Нажмите **«✏️ Змінити»**, вставьте текст в поле ввода, отредактируйте и отправьте
   одним сообщением.
5. Бот проверит шаблон и покажет, как будут выглядеть посты на примерах товаров
   (iPhone, Android-смартфон со скидкой, iPad, MacBook).
6. Если всё хорошо, нажмите **«✅ Зберегти»**. Если нет, просто отправьте
   исправленный текст ещё раз: бот снова покажет пример.

Чтобы выйти без изменений, отправьте `/cancel` или нажмите «❌ Скасувати».

Кнопка **«👁 Попередній перегляд»** показывает, как выглядят посты с текущим шаблоном.

---

## Поля — данные товара

Поле пишется **латиницей в фигурных скобках**, точно как в таблице. Вместо него
бот подставит данные из RoApp.

| Поле                 | Что подставится                                         |
|----------------------|---------------------------------------------------------|
| `{name}`             | название товара                                         |
| `{price}`            | цена; если цена снизилась — ~~старая~~ → новая          |
| `{screen}`           | экран                                                   |
| `{processor}`        | процессор                                               |
| `{camera}`           | камера                                                  |
| `{battery}`          | АКБ                                                     |
| `{complect}`         | комплектация                                            |
| `{screen_condition}` | состояние экрана                                        |
| `{body_condition}`   | состояние корпуса                                       |
| `{os}`               | операционная система (Mac OS / Windows)                 |

**Если поле у товара не заполнено, вся строка с этим полем не попадёт в пост.**
Например, строка `📸 Камера: {camera}` пропадёт, если в RoApp камера не указана.

## Пометки — строка только для части товаров

Пометка ставится **в самом начале строки**, в квадратных скобках. Строка будет
показана только у товаров, которые подходят под условие.

| Пометка      | Строка видна, если…                          |
|--------------|----------------------------------------------|
| `[Apple]`    | товар Apple (iPhone, iPad, MacBook)          |
| `[Android]`  | товар НЕ Apple                               |
| `[США]`      | Apple, американская версия (eSIM)            |
| `[Європа]`   | Apple, европейская версия                    |
| `[LTE]`      | планшет с SIM / LTE                          |
| `[WiFi]`     | планшет только с Wi-Fi                       |
| `[Стан]`     | заполнено состояние экрана или корпуса       |
| `[Нова АКБ]` | аккумулятор заменён на новый                 |

Пример:

```
[Apple] 🔒 iCloud: чистий
[Android] 🔒 Google акаунт: чистий
```

У iPhone будет строка про iCloud, у Samsung — про Google-аккаунт. Сама пометка в
пост не попадает.

## Оформление

- **Жирный**, *курсив*, ~~зачёркнутый~~, ссылки: выделите текст → «Форматирование»
  (стандартное меню Telegram). Бот сохранит оформление.
- Эмодзи — как обычно.
- Пустые строки между блоками сохраняются. Если из-за пустых полей подряд оказались
  две пустые строки, останется одна.
- **Подвал добавляется к каждому посту автоматически**, вставлять его в шаблон
  товара не нужно.
- Максимальная длина поста в Telegram — 1024 символа. Если пост получился длиннее,
  бот обрежет середину, а подвал оставит. Если на примере пост выходит слишком
  длинным, бот предупредит об этом.

---

## Когда изменения вступают в силу

- **Новые посты** сразу публикуются с новым шаблоном.
- **Уже опубликованные посты** обновятся при следующем `/import` (или при
  автоимпорте): бот перепишет подписи всех постов в канале. Telegram ограничивает
  скорость, поэтому при большом количестве постов это занимает несколько минут.
- Посты с пометкой «ПРОДАНО» не переписываются.

## Ошибки и как их исправить

| Сообщение бота                          | Что сделать                                                    |
|-----------------------------------------|----------------------------------------------------------------|
| «Невідомі поля: {prise}»                | опечатка в поле — сверьте с таблицей полей                     |
| «Невідомі позначки на початку рядка»    | опечатка в пометке — сверьте с таблицей пометок                |
| «У шаблоні немає {name}» / «{price}»    | предупреждение: в посте не будет названия / цены               |
| «Пост виходить задовгим»                | сократите шаблон, иначе часть текста обрежется                 |
| «Telegram не прийняв пост»              | уберите необычное оформление (например, премиум-эмодзи)        |

---

## Вернуть как было

`/template` → категория → **«↩️ Стандартний шаблон»** → подтвердите. Шаблон
вернётся к исходному виду. Кнопка появляется, только если шаблон менялся.
Чтобы обновить уже опубликованные посты, запустите `/import`.
